## 6. Функции

- **Каталог:** категории с подкатегориями, поиск по названию и описанию, подсказки и история поиска, фильтры (цена от/до, только в наличии), сортировка (рекомендуемые, популярные — по реальным продажам, цена ↑/↓, новинки, по названию), пагинация.
- **Корзина:** гостевая в браузере → объединяется с аккаунтом при входе; проверка наличия; лимиты количества.
- **Заказ:** только для вошедших; самовывоз; остатки списываются в транзакции при создании и возвращаются при отмене; статусы PENDING → CONFIRMED → PREPARING → READY_FOR_PICKUP → COMPLETED / CANCELLED с историей; снимок названия и цены в заказе; уведомления KY/RU.
- **Избранное, отзывы** (только после покупки, с модерацией), **FAQ** (поиск, разделы), **подписка** (согласие + подтверждение по email, защита от повторов, выгрузка CSV).
- **Конструктор наборов:** выбор, количество, сумма с сервера, 3D-коробка, «в корзину одним нажатием», сохранение.
- **NUSKA AI** — см. п. 9.
- **SEO:** metadata, Open Graph, canonical + hreflang, sitemap, robots, structured data (Product, FAQPage).
- **Вход через Google** (OAuth 2.0 + PKCE, ключи только в Render; аккаунт с тем же email привязывается).
- **Безопасность:** httpOnly-cookie сессии с ротацией, роли USER/ADMIN на сервере, rate limiting, CORS, Helmet, API доступен только через прокси сайта с секретом, проверка всех входных данных, безопасная загрузка изображений (тип и размер), журнал действий админа, секреты только в окружении.

## 7. 3D-сцены (все процедурные — без скачивания моделей)

1. **Hero:** фон — картинка компании (юрта, горы, подиум); на подиуме по эллипсу медленно движутся 3D-упаковки (кымыз, бал, нават, сары май, бешбармак); при наведении — название и **цена из базы**, выбор (в 3D или кнопками под подиумом) — карточка «В корзину».
2. Блок «Традиции» — фото в орнаментальной рамке (низкополигональная юрта убрана по просьбе заказчика).
3. **3D-упаковка товара:** бутылка, банка, коробка, пакет (выбирается в админке); вращение, кнопки приближения/отдаления.
4. **3D-коробка конструктора:** выбранные продукты появляются внутри.
5. Символ NUSKA AI — SVG-орнамент (отдельной страницы помощника больше нет, только окно).

Везде: отдельная лёгкая загрузка, пауза вне экрана, облегчённый режим на телефонах, `prefers-reduced-motion`, 2D-замена без WebGL.

## 8. Анимации

Единая система на Framer Motion: появление секций (`Reveal`), параллакс (`Parallax`), переходы страниц, «полёт товара в корзину», рисующийся орнамент кочкор-мүйүз в логотипе и иконках преимуществ, hover-эффекты карточек, mega menu, аккордеоны FAQ и футера, плавная шапка при прокрутке. Всё отключается при `prefers-reduced-motion`.

## 9. Статус NUSKA AI

- **Готово:** модуль сервера (сервис, контроллер, DTO, провайдер Claude с инструментами каталога, системный промпт, лимиты), маленькое окно на любой странице (без отдельной страницы), админка.
- **Сейчас работает в режиме каталога** — ключ AI не подключён, и чат честно это пишет. В этом режиме помощник уже подбирает наборы по бюджету и для дасторкона/подарка, показывает каталог и объясняет самовывоз — только по данным базы.
- **Чтобы включить Claude:** Render → `nuska-etno-api` → Environment → `ANTHROPIC_API_KEY` (платный ключ). Модель по умолчанию `claude-opus-5-5`, дешевле — `AI_MODEL=claude-haiku-5-5`; лимит `AI_DAILY_LIMIT` (300/день).
- Помощник **никогда сам не меняет корзину, заказы, оплату и аккаунт** — только предлагает набор с кнопкой.
- Связка с Claude проверена тестом на поддельном API; **с настоящим ключом ещё не запускалась**.

## 14. Оставшиеся задачи

1. **Vercel:** проверить, что сайт открывается по адресу из Domains и показывает товары (переменные `API_INTERNAL_URL`, `API_PROXY_SECRET`, `NEXT_PUBLIC_SITE_URL` + Redeploy).
2. **cron-job.org:** ping `https://nuska-etno-api.onrender.com/api/health` каждые 10 минут.
3. **Пункт самовывоза:** добавить реальный в админке (без него нельзя оформить заказ).
4. **Почта (Brevo):** `SMTP_*` в Render — для писем подтверждения, сброса пароля, подписки.
5. **Фото товаров (Supabase Storage):** `S3_*` в Render, затем загрузка фото в админке.
6. **NUSKA AI:** при желании — ключ `ANTHROPIC_API_KEY` (платно).
7. **Зависимости:** осталось 3 предупреждения — `@nestjs/core` (умеренное, нужен переход на NestJS 11 — отдельная крупная задача), `zod` внутри Anthropic SDK (наш код его не использует для проверки ввода), `deepmerge-ts` внутри Prisma CLI (используется только при миграциях).
8. **Онлайн-оплата:** не подключена (по ТЗ — после решения компании); сейчас оплата при получении, статус оплаты меняет админ.
9. **Ограничения бесплатных тарифов:** Vercel Hobby — только некоммерческое использование; Render Free засыпает. Для коммерческого запуска нужен платный тариф или другой хостинг.
